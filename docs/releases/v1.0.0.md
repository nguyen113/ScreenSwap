# ScreenSwap v1.0.0

ScreenSwap’s first v1 release brings Swap, Move, and Call / Return together in a
macOS menu-bar app for Apple silicon and Intel Macs running macOS 14 or later.

## Features and quick instructions

- **Swap selected windows:** left-click the icon or press **Control–Shift–S**.
  Right-click to choose individual windows and exactly two active displays.
- **Move focused window:** middle-click the icon or press
  **Control–Option–Shift–S** to move the focused window to the other display.
- **Call / Return:** press **Control–Shift–C** to bring the topmost eligible
  window from the other display to the primary and bring it forward. Press
  again to restore the same window’s saved display, position, and size.
- **Choose primary display:** right-click → **Primary Display** → choose a
  monitor or **Follow macOS**. The preference survives app restarts without
  changing macOS display settings.
- **Mouse bindings:** right-click → **Left Click** / **Middle Click** to choose
  Swap, Move, or Call / Return. Scroll over the icon to cycle middle click.
- **Settings:** customize all three shortcuts and enable launch at login.
- Proportional placement across unequal displays, per-window selection,
  fixed-size window handling, verified moves with best-effort restoration,
  directional icons, and Reduce Motion-aware feedback.

Return or **Cancel Return — Keep Window Here** before using Swap, Move, or
changing the primary display. Return recovery is kept only until the app quits.

## Installation and limitations

Download the DMG and drag ScreenSwap to Applications, or extract the ZIP and
move ScreenSwap.app to Applications. Launch it and enable **System Settings →
Privacy & Security → Accessibility → ScreenSwap**.

These downloads are **ad-hoc signed and not Apple Developer ID signed or
notarized**. If macOS blocks launch, use **Privacy & Security → Open Anyway**
after attempting to open the app. Updates may require Accessibility approval
again.

Native macOS full-screen Spaces are unsupported; exit full screen first.
Spanning, minimized, transient, non-movable, and unavailable windows are
excluded. Each action operates on exactly two selected displays.

See the [README](https://github.com/nguyen113/ScreenSwap#readme) for setup and
usage. Automated and packaging checks are recorded in
[the release validation](https://github.com/nguyen113/ScreenSwap/blob/v1.0.0/docs/validation/release-v1.0.0.md).
