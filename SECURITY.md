# Security Policy

## Reporting a Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Once this repository is public, maintainers must enable GitHub Private
Vulnerability Reporting before announcing or broadly distributing ScreenSwap.
After Private Vulnerability Reporting is enabled, report vulnerabilities through
the repository's private vulnerability reporting form.

Please include:

- affected ScreenSwap version
- macOS version
- reproduction steps
- expected behavior
- observed behavior

Do not include private documents, window contents, credentials, or other
sensitive information.
